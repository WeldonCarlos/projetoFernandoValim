# Projeto Fernando Valim · Interface Inicial

Estrutura inicial de interface em React e TypeScript, com layout e cabeçalho usando Material UI.

## O que o projeto apresenta

- Componente de layout compartilhado.
- Componente de cabeçalho.
- Ambiente Vite com TypeScript e ESLint.

## Tecnologias

React · TypeScript · Vite · Material UI

## Executar localmente

```bash
git clone https://github.com/WeldonCarlos/projetoFernandoValim.git
cd projetoFernandoValim
npm install
npm run dev
```

Abra o endereço informado no terminal.

## Comandos disponíveis

| Comando | Uso |
| --- | --- |
| `npm run dev` | `vite` |
| `npm run build` | `tsc -b && vite build` |
| `npm run lint` | `eslint .` |
| `npm run preview` | `vite preview` |

Os scripts são os definidos em `package.json`; sua presença não indica que foram executados nesta revisão de documentação.
